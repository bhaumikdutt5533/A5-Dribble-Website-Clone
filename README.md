🎨 Dribbble Website Clone

A responsive **Dribbble website clone** created as part of a web development assignment.
The project focuses on recreating the visual layout, navigation, designer showcase, search section, categories, filters, and footer of the original Dribbble website.

🔗 Live Demo

[View Live Website](https://a5-dribble-website-clone.vercel.app/)

📌 About the Project

This project is a frontend clone of **Dribbble**, a platform for discovering and showcasing creative design work.
The main goal of this assignment was to practice building a modern, visually-focused website from scratch while working with layouts, responsive design, navigation, cards, images, typography, and UI elements.

✨ Features

🏠 Dribbble-inspired homepage
🔍 Search bar for discovering design work
📈 Trending search suggestions
🎨 Design categories including:

  * Animation
  * Branding
  * Illustration
  * Mobile
  * Print
  * Product Design
  * Typography
  * Web Design
* 🖼️ Designer/work showcase cards
* 👤 Designer information and statistics
* 🔘 Sign Up and Log In buttons
* 🧭 Navigation menu
* 📱 Responsive layout
* 📄 Dribbble-inspired footer
* ⚡ Deployed using Vercel

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Vercel
